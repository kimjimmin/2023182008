
idle 상태에서 a를 누르면 소년은 자동 [무적런]상태가 되어 키조자 없이도 계속 좌우로 이동하게된다. 

[무적런] 상태에서는 소년의 속도가 빨라지고 크기가 확대되어야한다.

[무적런] 상태에서는 좌우로 움직이는데 화면의 좌측 또는 우측 끝에서 자동으로 방향이 전환되어야한다.
(여기서 처음 움직이는 방향은 전에 보고있던 방향으로 정한다.)

[무적런] 상태 지속 5초후 다시 idle 상태로 돌아간다. 
만약 [무적런] 상태에서 방향키가 눌리면 무적런이 취소되고 눌린 방향으로 움직이는 Run 상태로 돌아간다.
